# 牧場ノートの使い方

配合を調べ、計画を保存し、産まれた所有馬の記録につなげるための簡単なマニュアルです。
インストールとAPIの設定は[README](../README.md#起動)を参照してください。

## やりたいことから探す

| やりたいこと | 使う画面 |
|---|---|
| 父と母を決めて配合理論や血統を確認する | [配合確認](breeding.md#配合確認) |
| 条件に合う相手や数世代の経路を探す | [配合探索](breeding.md#配合探索) |
| 凝った配合を繰り返す周期を探す | [凝った配合ループ探索](breeding.md#凝った配合ループ探索) |
| 配合手順と産まれた馬を管理する | [配合計画](breeding.md#配合計画) |
| 所有馬の能力・血統・戦績を記録する | [所有馬](horses.md) |
| 冠名を設定し、馬名の候補を考える | [命名候補](horses.md#命名候補) |
| 馬やレースのデータを調べる・直す | [データ](data-and-settings.md#データを調べる編集する) |
| ゲーム画面から情報を取り込む | [写真の取り込み](data-and-settings.md#写真から取り込む) |
| ゲームの進行に合わせて状態を保存・復元する | [セーブ・ロード](data-and-settings.md#セーブロード) |
| 愛馬の歩みを読み物にする | [おまけ：愛馬の一篇](horse-story.md) |

## 最初の流れ

1. 「設定」の「牧場設定」で牧場名と冠名を入力します。画面右上の年表示から、ゲーム内の年も設定します。
2. 「所有馬」で馬を登録します。写真からの取り込みも使えます。
3. 「配合確認」で組み合わせを調べるか、「配合探索」で相手や経路を探します。
4. 気に入った経路を計画として保存し、ゲームで産まれた馬を紐付けます。
5. 能力や戦績を記録し、区切りのよいところでセーブします。

写真の読み取り・命名候補・愛馬の一篇にはAPIの設定が必要です。
配合の確認・探索、データの閲覧、手動での登録はAPIキーなしで使えます。
